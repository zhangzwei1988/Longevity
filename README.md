# 长寿 Longevity

> 健年 Healthspan 的战略与运营项目。

本项目用于管理“长寿”项目的完整事实、健年母品牌、内容与证据体系、用户研究、专业协作以及未来服务实验。

## 当前阶段一句话

先用真实、克制、循证且高度利他的内容打磨基本功，吸引理性、有健康意识的家庭健康决策者；在持续互动中理解真实问题，让商业服务从反复出现、仅靠内容无法解决的需求中自然生长。

## 已确定的架构

```text
长寿 Longevity（项目）
└── 健年 Healthspan（面向用户的母品牌）
    ├── 内容与证据体系（当前主线）
    ├── 用户互动与需求研究（当前主线）
    ├── 专业协作与审核能力（逐步建设）
    └── 健康管理服务（由真实需求逐步验证）
```

## 当前不做

- 不同时运营多个垂直账号。
- 不开发完整健康管理平台、用户系统或自动诊断系统。
- 不以“体检报告解读”作为核心卖点。
- 不提供诊断、处方、停换药或疗效承诺。
- 不收集超出交付所需的个人健康信息。
- 不延续原项目的重型三平台内容生产流水线。
- 不为了验证商业化而牺牲内容基本功、用户价值和长期信任。

## 项目原则

1. **先创造价值，再验证服务**：内容先解决真实问题，商业化从用户反复表达的深层需求中生长。
2. **卖清晰度，不卖诊断**：帮助用户整理、排序、取舍和准备下一步行动。
3. **内容服务于能力、信任与需求发现**：不把每条内容都变成销售素材。
4. **隐私由架构保证**：默认最少收集，本地处理优先，健康资料不得进入 Git。
5. **用真实反馈修正项目**：评论、访谈、实际使用、付费、交付和转介绍分别提供不同层级的证据。
