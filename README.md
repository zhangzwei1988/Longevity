# 长寿 Longevity

> 健年 Healthspan 的战略与运营项目。

本项目用于管理「健年」母品牌、「多活十年 Lab」内容账号、首个付费产品「健年·未来十年健康盘点」，以及未来垂直产品的验证过程。

## 当前阶段一句话

通过真实、克制、循证的内容，找到那些已经为健康投入很多、却仍缺少清晰解决路径的人；先帮助用户建立未来十年的健康管理底图，再从真实订单中决定下一条垂直产品线。

## 已确定的架构

```text
健年 Healthspan（母品牌）
├── 多活十年 Lab（当前唯一主账号）
├── 健年·未来十年健康盘点（首个付费产品）
│   ├── 未来十年健康底图（含健康投入复盘）
│   ├── 问题领域循证说明书
│   ├── 专业沟通包
│   └── 30天观察卡
├── 健年本地病历脱敏工具（免费信任工具，待验证后开发）
└── 未来垂直产品与账号（康复、体脂、睡眠、脱发等，由订单决定）
```

## 当前不做

- 不同时运营多个垂直账号。
- 不开发完整健康管理平台、用户系统或自动诊断系统。
- 不以“体检报告解读”作为核心卖点。
- 不提供诊断、处方、停换药或疗效承诺。
- 不收集超出交付所需的个人健康信息。
- 不延续原项目的重型三平台内容生产流水线。

## 项目原则

1. **先成交，后扩张**：新账号、新工具和自动化都必须由真实需求触发。
2. **卖清晰度，不卖诊断**：帮助用户整理、排序、取舍和准备下一步行动。
3. **内容服务于信任与需求发现**：不是为了构建庞大的媒体生产系统。
4. **隐私由架构保证**：默认最少收集，本地处理优先，健康资料不得进入 Git。
5. **用案例修正项目**：文档是假设，付费、执行和转介绍才是证据。
