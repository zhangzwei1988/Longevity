## 使用方式

双击 `index.html` 即可在浏览器中打开。

- 鼠标滚轮、触控板或滑动：翻页；
- 方向键、Page Up / Page Down、空格键：翻页；
- Home / End：跳到第一页或最后一页；
- 右侧圆点：直接跳转。

推荐在桌面浏览器中全屏展示。手机可以正常阅读，但不是本次会谈的主要版式。
