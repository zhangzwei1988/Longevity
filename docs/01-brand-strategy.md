# 品牌战略

## 品牌角色

### 健年 Healthspan

健年是长期母品牌，承载专业标准、隐私原则、产品体系和高端服务。

现阶段对外定位：

> 帮助忙碌、理性的中高收入家庭，把零散、复杂的健康信息，转化为清晰、可靠、可执行的健康决策。

现阶段健年不是医疗权威，也不替代医生。它首先是健康信息的研究者和整理者、健康决策方法的提供者、家庭健康问题的观察者，以及未来健康管理服务的建设者。

品牌最终追求的不是一个抽象寿命数字，而是：

> 让有活力的人生，尽可能长。

这里的“活力”不是由健年作出的医学判断，而是用户希望长期保留的行动、精力、认知、独立生活和社会参与能力。

长期逻辑：

1. 年老时的生活自由，来自更早时期对健康和功能能力的持续积累；
2. 健康管理不是一次性消费，而是反复识别关键限制因素、行动、记录和复盘；
3. 当前产品先识别信息、认知、执行和资源上的管理断点；
4. 涉及身体机能、疾病和医学风险的“短板”，必须由对应领域的合格专业人员评估。

### 多活十年 Lab

多活十年 Lab 是当前阶段的内容账号和公众入口。它负责：

- 用真实问题吸引目标用户；
- 把医学研究和服务选择翻译成普通人能用的判断；
- 展示创始人的探索、案例和方法；
- 为健年的产品建立信任和需求线索。

它不是未来所有服务的公司名称，也不需要承载所有垂直内容。

## 目标品牌印象

用户接触健年后，应形成四个判断：

1. 这里不会利用我的焦虑推销产品。
2. 这里会说明依据、限制和不确定性。
3. 这里能帮我从复杂信息中找到优先级。
4. 这里尊重隐私，也知道什么时候应该交给医生。
5. 这里能把硬核科学证据准确地翻译成人能听懂、能行动的话。

## 品牌价值观

| 价值观 | 行为要求 |
|---|---|
| 循证 | 重要判断标注来源和证据等级，不用单篇论文包装确定结论 |
| 客观 | 不以销售某个设备、补剂或疗程为前提 |
| 克制 | 不承诺治愈，不夸大风险，不制造恐惧 |
| 可执行 | 每次交付都要帮助用户做出少数明确决定 |
| 长期主义 | 同时考虑短期缓解、长期能力和持续成本 |
| 隐私优先 | 默认少收资料，优先使用本地脱敏和用户可控的提交方式 |

## 一句话表达

品牌目的：

> 让有活力的人生，尽可能长。

品牌方法：

> 科学养生，少走弯路。

当前产品定位：

> 健年帮助高健康投入用户看清自己已经做了什么、哪里断了、下一步最值得做什么。

面向公众的解释：

> 未来的活力，需要从今天开始投资。健年帮助你找到长期健康管理中最值得优先关注的一环。

内部研究假设：

> 持续识别并改善影响功能能力的可干预因素，尽可能延缓功能下降，延长保持活力、独立和自主的生命阶段。

“生理年龄”只能作为未来可能研究的观察指标，不能作为健年当前产品的总分、效果证明、寿命预测或宣传承诺。

## 品牌边界

健年可以：整理非诊疗信息、梳理消费和行动路径、解释公开证据、识别信息冲突和缺口、准备就医问题、设计非医疗行为的跟踪方式。

健年不能：冒充医疗机构、判断病情轻重、诊断或排除疾病、推荐治疗、开具处方、指导停换药、保证疗效，或让 AI 替代有资质的专业人员作出医学结论。
