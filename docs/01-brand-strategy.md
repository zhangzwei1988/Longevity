# 品牌战略

## 品牌角色

### 健年 Healthspan

健年是长期母品牌，承载专业标准、隐私原则、产品体系和高端服务。

品牌要解决的不是“让人永远年轻”，而是：

> 帮助用户减少健康决策中的混乱、浪费和失控，把健康寿命变成一套可以持续管理的系统。

### 多活十年 Lab

多活十年 Lab 是当前阶段的内容账号和公众入口。它负责：

- 用真实问题吸引目标用户；
- 把医学研究和服务选择翻译成普通人能用的判断；
- 展示创始人的探索、案例和方法；
- 为健年的产品建立信任和需求线索。

它不是未来所有服务的公司名称，也不需要承载所有垂直内容。

## 目标品牌印象

用户接触健年后，应形成四个判断：

1. 这里不会利用我的焦虑推销产品。
2. 这里会说明依据、限制和不确定性。
3. 这里能帮我从复杂信息中找到优先级。
4. 这里尊重隐私，也知道什么时候应该交给医生。

## 品牌价值观

| 价值观 | 行为要求 |
|---|---|
| 循证 | 重要判断标注来源和证据等级，不用单篇论文包装确定结论 |
| 客观 | 不以销售某个设备、补剂或疗程为前提 |
| 克制 | 不承诺治愈，不夸大风险，不制造恐惧 |
| 可执行 | 每次交付都要帮助用户做出少数明确决定 |
| 长期主义 | 同时考虑短期缓解、长期能力和持续成本 |
| 隐私优先 | 默认少收资料，优先使用本地脱敏和用户可控的提交方式 |

## 一句话表达

内部定位：

> 健年帮助高健康投入用户看清自己已经做了什么、哪里断了、下一步最值得做什么。

面向公众的候选表达：

> 让每一笔健康投入，都有依据、有目标、有复盘。

长期品牌表达：

> 让健康寿命变成一套可管理的系统。

以上均为当前版本，应通过用户原话继续优化。

## 品牌边界

健年可以：整理信息、梳理路径、解释证据、识别冲突和缺口、准备就医问题、设计跟踪方式、连接合格专业人员。

健年不能：冒充医疗机构、诊断疾病、开具处方、指导停换药、保证疗效，或让 AI 替代有资质的专业人员作出医学结论。
