## 一、唯一事实源

`/Users/john/CodeShop/Studio/Longevity` 是“长寿”项目详细事实和日常工作的唯一事实源。

这里保存：

- 目标用户、问题假设和用户研究；
- 内容选题、证据研究、脚本、发布与复盘；
- 医疗、隐私和专业审核边界；
- 产品与服务假设；
- 运营实验、结果和重大项目决策；
- 网站及其他项目资产。

## 二、LifeOS 保存范围

`/Users/john/CodeShop/LifeOS` 是个人总系统，不保存长寿项目详细业务文档的平行副本。

LifeOS 只保存：

- 长寿在个人项目组合中的位置；
- 当前阶段和一句话状态；
- 每周可投入时间、健康、财务等个人资源约束；
- 影响其他项目或人生安排的重大决策；
- 下一阶段关键行动摘要；
- 指向本仓库的稳定入口。

LifeOS 不保存：

- 详细选题库、脚本和证据笔记；
- 用户访谈全文和业务反馈明细；
- 完整品牌、内容、运营和商业方案副本；
- 产品交付模板和实验日志；
- 网站源码和大型资产。

## 三、什么时候同步回 LifeOS

只有出现以下变化时才同步摘要：

1. 项目目标、定位或阶段发生变化；
2. 每周投入或优先级需要调整；
3. 出现重要合作、重大支出或现实资源承诺；
4. 服务进入真实收费、交付或规模化阶段；
5. 项目风险开始影响健康、财务、家庭或其他项目；
6. 项目暂停、结束或转向。

普通选题、脚本修改、论文笔记和日常内容数据不回写 LifeOS。
