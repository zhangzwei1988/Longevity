## 2026-07-24 最新方向

此前“销售优先、立即验证未来十年健康盘点”的方案已降级为历史商业假设，不再是当前执行主线。最新决定见 [决策 0009](../decisions/0009-content-foundation-and-organic-commercialization.md)。

当前阶段转为：

1. 先打磨选题、证据研究、脚本、拍摄、剪辑、分发、互动和复盘等内容基本功；
2. 内容极度利他，不以每条内容直接成交为目标；
3. 通过评论、私信、访谈和工具使用理解用户真实需求；
4. 商业化保留长期方向，但具体产品和中间路径由真实需求与服务实践逐步验证；
5. “硬核健康证据的人话翻译”既是独立内容支柱，也是全部健康内容的底层研究标准。

当前优先级以本节为准；下文保留的旧产品和成交内容属于历史假设或未来候选，不代表当前必须执行。

## 当前品牌叙事

- 品牌目的：让有活力的人生尽可能长；
- 品牌方法：科学养生，少走弯路；
- 长期逻辑：未来的行动能力、精力和生活自主，需要从更年轻时开始积累；
- 当前产品作用：先帮助用户盘清既往投入和信息状态，找到长期健康管理中最值得优先关注的一环；
- 对外不承诺降低生理年龄、延长寿命或精准诊断身体短板。

## 创始人洞察

创始人过去一年因腰椎间盘突出、腰肌劳损及骨盆/髋部相关问题，在医院、康复机构、治疗仪、按摩设备和运动腰带等方面累计投入至少 5 万元，但仍未获得清晰、连续、可验证的解决路径。

最强烈的不满不是“没有任何治疗”，而是：

- 不同机构各自销售一个局部方案，没有人为完整结果负责；
- 用户难以知道具体问题、干预目标和评估指标；
- 购买了很多服务和产品，却无法判断哪些有效、哪些重复、哪些缺失；
- 缺少一张能连接资料、选择、执行、复盘和转诊的路径图。

这构成了当前产品的核心假设：

> 一部分高健康投入用户缺少的不是更多建议，而是对已有信息、消费和行动进行客观整理、优先级判断与下一步决策支持。

## 当前最重要的未知数

1. 用户是否愿意为“盘清过去并建立未来十年的健康管理底图”付费？
2. 哪一种问题最容易触发购买：康复、体脂、睡眠、脱发、代谢，还是跨问题的健康投入混乱？
3. 用户最有价值感的交付物是什么：消费地图、证据分析、问题清单、行动排序还是复盘陪伴？
4. 创始人本人能够可靠交付到什么深度，哪些部分必须引入医生、物理治疗师、营养师等专业人员？
5. 从一次未来十年健康盘点到长期高端服务，中间最自然的续费产品是什么？

这些问题不能靠继续写战略解决，必须由访谈、付费和实际交付回答。

## 当前服务边界

首批体验版不处理重大疾病、已确诊疾病的治疗决策、急性或进行性症状，也不负责判断用户是否属于“亚健康”。只接收目标明确的非诊疗需求，例如长期能力目标整理、健康消费复盘、生活方式观察和就医前资料整理。

只要用户希望获得诊断、治疗建议、用药调整，或资料显示问题可能超出非诊疗范围，就不接单或立即中止，并建议用户前往有资质的医疗机构。

## 当前交付价值

未来十年健康盘点不是疾病风险评估，而是帮助用户建立长期健康管理起点。用户应当明确带走四件东西：

1. 一张未来十年健康底图：写清希望长期保留的能力、当前生活方式和过去的健康投入；
2. 一份问题领域循证说明书：用通俗语言理解权威资料中已经知道和仍不知道的内容；
3. 一套专业沟通包：下次与医生或其他合格专业人员沟通时知道带什么、问什么；
4. 一张 30 天观察卡：记录一个非医疗行为、一个结果指标和一个复盘日期。

健康投入复盘保留为“未来十年健康底图”中的一个模块，不再作为顶层产品身份。循证说明书针对“问题领域”翻译通用知识，不根据用户个人症状作医学判断。

## 表达层与执行层

对外宣传按照用户容易理解的时间线表达：

- 过去：把健康记录、身体感受和既往投入整理清楚；
- 现在：理解通用证据，识别信息、认知、执行和资源缺口；
- 未来：明确十年后想保留的能力，倒推出当前非医疗观察和专业确认事项。

内部执行不按三个阶段分别生产三套报告，仍采用“一图、一书、一包、一卡”的标准交付。时间线负责讲故事，交付结构负责保证质量。
