# 目标用户与核心问题

## 第一阶段目标用户

优先服务满足多数特征的人：

- 35—55 岁，工作繁忙，时间成本高；
- 过去一年为某个健康问题投入过较多金钱和精力；
- 尝试过至少三种产品、机构或解决方案；
- 手中有零散的检查、建议和消费记录；
- 问题仍未解决，或者不知道是否正在改善；
- 愿意为客观整理、节省试错和提高决策质量付费；
- 当前需求属于健康消费、生活方式执行或就医准备，而非疾病诊断和治疗；
- 没有需要本服务判断的急性、进行性或重大疾病问题。

“高净值”是长期服务对象，但第一阶段不把财富标签作为唯一筛选标准。更重要的是：问题真实、投入明显、路径混乱、付费意愿存在。

## 购买触发

用户通常不会因为“想活得更久”立即付款，更可能在以下时刻购买：

- 已经花了很多钱，效果仍不明确；
- 不同医生或机构的建议互相矛盾；
- 买了很多设备、补剂、课程或非处方服务，不知道哪些缺少目标和验证方法；
- 面临下一笔较大的健康支出，希望先判断值不值得；
- 想去更好的医院或机构，却不知道该带什么资料、问什么问题；
- 感觉长期被同一个问题消耗，希望重新建立可追踪的路径。

## 核心工作任务

用户雇用健年，不是为了再得到一份泛泛的健康报告，而是希望完成四件事：

1. **整理**：把过去的检查、建议、产品和花费放到一张图上。
2. **判断**：区分来源清楚、目标清楚、可以记录、信息不足和必须交给专业人员的部分。
3. **取舍**：确定哪些消费和非处方健康尝试继续、暂停、观察或补充信息；涉及治疗和用药时，只整理需要向合格专业人员确认的问题。
4. **复盘**：为下一阶段设置可以观察的目标和时间点。

在此基础上，用户还需要把眼前的问题放回长期生活中：十年后希望继续保留什么能力，今天的健康投入是否真正服务于这些能力。产品不预测寿命，也不对疾病风险评分，而是帮助用户建立长期健康管理的方向感。

## 不以这些作为首要入口

- 单纯体检报告解读：同质化高，用户已有大量低价替代品。
- 泛长寿评估：概念过大，缺少立即购买理由。
- 自动 AI 问诊：风险高，信任弱，也不符合项目当前能力。
- 单一产品推荐：容易与客观、反智商税的品牌承诺冲突。

## “亚健康”不是准入诊断

对外可以使用“生活状态不好”“健康投入很多但没有结果”等用户语言，但不能由健年判断某个人只是“亚健康”。一些严重问题早期也可能表现为疲劳、疼痛、睡不好或体重变化。

因此，首批体验版以服务任务划界，而不是以疾病名称划界：

- 可以整理用户已经发生的健康消费和非处方生活方式尝试；
- 可以帮助用户准备下一次就医要带的资料和要问的问题；
- 不能解释未明确的症状、判断是否患病或评估疾病严重程度；
- 不能对重大疾病、慢性病治疗、术后康复、药物和处方治疗作取舍建议；
- 边界不清时默认不接收，而不是尝试“先看看”。

## 待验证的垂直问题

| 方向 | 初步优势 | 主要风险 | 当前处理 |
|---|---|---|---|
| 康复/慢性疼痛 | 创始人经验深，付费痛感强，路径碎片化明显 | 属于高专业边界，可能涉及诊疗 | 只做内容与需求研究；没有合格专业伙伴前不销售康复方案 |
| 体脂管理 | 结果可测量，需求广，容易形成连续服务 | 市场拥挤，容易沦为普通减肥服务 | 测试“高投入仍反复”人群 |
| 睡眠 | 痛感强，执行和跟踪适合产品化 | 需要识别睡眠障碍并及时转诊 | 内容测试，不先承诺专项产品 |
| 脱发 | 视觉化强，购买触发明确 | 竞争激烈，临床判断仍需专业人员 | 观察，不作为第一选择 |
| 血糖/血压 | 指标清晰、长期价值高 | 医疗体系覆盖较成熟，医疗边界明显 | 只做通用循证科普和专业沟通准备，不先独立开号 |

最终选择依据是付费、交付效果和转介绍，不是话题播放量。
