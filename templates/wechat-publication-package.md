## 发布前检查

- [ ] 内容类型明确，H3 未进入发布；H1 的账号资质与专业责任均已确认；
- [ ] 不存在 `NeedsPlatformQualification`、`NeedsProfessionalReview`、`NeedsAdvertisingReview` 或 `Blocked`；
- [ ] 标题、摘要、正文承诺一致；
- [ ] 所有图片均已进入本期工作区；
- [ ] AI／文学化组合场景已在素材清单记录性质，并在必要时于文末统一披露，没有冒充真实案例；
- [ ] 每张图都有准确 Alt 文本；可见图注只用于来源、版权、数据口径或关键限制，不复述画面、不暴露制作语言；
- [ ] 图片中没有错误文字、数字、机构、产品或疗效暗示；
- [ ] 375px 预览没有横向溢出；
- [ ] 微信后台粘贴后样式和图片完整；
- [ ] 2.35:1 与 1:1 封面裁切均可用；
- [ ] 封面未放品牌小字；纯视觉图使用右下角叠字，文字信息图使用紧凑独立署名区；品牌名略加粗、无标签底纹且保留足够安全边距；
- [ ] 正文重点使用局部加粗；标题或提示中的实线／虚线交替有节奏且符合语义，没有把所有段落都装饰化；
- [ ] emoji 克制、辅助语境而不抢夺注意力，长文通常为 2—4 个且不超过 5 个；
- [ ] 每张正文图都有代入、情绪、冲突、解释或行动功能，没有为凑数量硬塞；
- [ ] 封面短标题主语或对象明确，单独阅读仍然通顺；
- [ ] 所有公众可见文字均未出现内部编号、版本状态或方括号语义标签；
- [ ] 来源、限制、CTA 和隐私边界未因排版丢失；
- [ ] 已检查商品、服务、机构、价格、商业合作、联系方式、二维码、链接和交易元素；科普没有变成未审查的广告或导流；
- [ ] 已检查账号名称、简介、菜单、标签、置顶评论和私信回复，不只检查正文；
- [ ] AI／合成内容已按本期计划和平台功能完成声明或标识，没有删除或规避标识；
- [ ] 公众号后台最新规则、账号认证和发布提示已在本次 G4 复核并记录日期；
- [ ] 文末使用低权重的“附录｜来源与说明”，与正文有明显层级差异，但资料和必要限制仍然清晰可读；
- [ ] G2/G3 状态符合要求；
- [ ] G4 人工批准。
