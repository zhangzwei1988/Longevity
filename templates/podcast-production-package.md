## 十二、TTS 前审核

- [ ] 统一内容包为 `G3Locked`
- [ ] 叙事底稿为 `CreatorConfirmed`
- [ ] 一期只完成一个任务
- [ ] 钩子在前一分钟内兑现
- [ ] 品牌识别简短，没有压住主题
- [ ] 人格来自声音动作，不靠连续段子或假口吃
- [ ] 组织稿没有新增事实、案例、数字或专业身份
- [ ] TTS 纯净稿不含制作标记、链接和内部 ID
- [ ] 多音字、数字、外语和引用已有发音处理
- [ ] AI 声音身份、授权和显式声明明确
- [ ] 关键限制没有被移到只有 Show Notes 才能看见的位置
- [ ] 封面和插图没有新增事实或制造医疗暗示
- [ ] 没有声称已生成音频、上传平台或通过 G4
