## 设计判断

健年承载长期信任、标准与未来服务；当前公众入口为多活十年 Lab。设计从「年」建立中文记忆，延伸末笔表示持续积累，让品牌既能用于今天的内容，也能用于未来经过验证的服务。

这是设计意图，尚无用户识别研究支持。「活力之环」和「功课书签」作为对照方案，未延展成第二、第三套完整品牌系统。

品牌表达分层如下，不把账号 slogan 全部堆在母品牌 Logo 下。

| 层级 | 固定表达 | 使用位置 |
|---|---|---|
| 品牌名 | 健年 Healthspan | 母品牌识别 |
| 品牌目的 / 主 slogan | 让有活力的人生，尽可能长。 | 品牌介绍、理念卡、品牌首页 |
| 品牌方法 | 科学养生，少走弯路。 | 方法说明 |
| 当前账号 | 多活十年 Lab | 内容封面、账号主页 |
| 账号简介 | 专替忙人做健康功课，帮你少踩坑、少花冤枉钱。 | 账号简介与公众介绍 |
| 账号短 slogan | 健康少踩坑，花钱少冤枉。 | 内容署名、视频收尾 |
| 新增备选传播短句 | 把活力，留给未来。 | 待确认的活动短句，不替换既有主张 |

Healthspan 沿用既有英文展示，不宣称具备独立商标可注册性。JIANNIAN 仅作拼音检索词；未擅自更换英文品牌。

## 品牌简介，可用于非销售型介绍

健年关注如何把有活力的生活保持得更久。我们从忙碌人群的真实健康问题出发，查依据、拆问题、看投入，帮助人们理解复杂信息，也说明已知、未知和需要专业人员确认的部分。多活十年 Lab 是健年的内容入口，专替忙人做健康功课。

## 除了 Logo 与 slogan，品牌必需的东西

本轮已经建立：名称层级、品牌定位、品牌承诺、语言基调、图形与字标、基本色与字体、组合规范、基础应用、版权来源记录和注册准备路径。

正式启用前还需要落实以下真实信息，无法用设计稿代替：

- 统一申请主体及权利归属，独立安全保存证照和代理委托材料；不把身份证明、联系信息或健康资料写入本仓库。
- 按真实业务完成商标检索与商品服务项目确认，锁定提交图样。
- 核对已有域名、账号名称、主体与可用性；本次不创建账号、不抢注域名、不替换线上头像。
- 启用时形成一份定稿记录，将 Logo、标准色、字标、字号与文件哈希锁定。
- 真实服务启动后，补齐对应的服务说明、合同页眉、专业身份、隐私告知与资料处理流程；以合格专业人员及实际合规条件为前提。
- 持续保留真实商标使用证据，建立申请、核准、续展与授权的简短台账。

当前不需要为了“像一个品牌”而先做吉祥物、补剂包装、制服、门店招牌或多个子品牌。

## 建议的定稿验证

1. 找 5—8 位接近目标人群的受访者，随机展示三个方向，每个先看 5 秒；不预先解释含义。
2. 问记住了什么、联想到什么行业、是否误认医疗机构、哪个更像长期可信的品牌；记录原话，避免只问喜不喜欢。
3. 查看 24 px 图形、180 px 横式组合与单色打印；一周后再看是否仍易识别。
4. 以品牌一致性、误认风险、可读性和近似检索共同决策；测试仅为小样本设计反馈，不包装成市场验证。
