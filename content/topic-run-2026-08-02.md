### xAI 异常说明

请求设置了 `max_tool_calls=1`、`max_output_tokens=900` 和关闭并行工具，但响应仍报告：

- `num_server_side_tools_used = 14`；
- `x_search_calls = 14`；
- 输入 92,962 tokens；
- 输出 1,867 tokens；
- 总计 94,829 tokens；
- `cost_in_usd_ticks = 1,113,724,000`，即 $0.1113724。

这说明顶层参数没有限制 X Search 内部的计费检索动作。后续不能再用“每个请求约一次工具费”估算。

### 后续每轮预算

默认暂停不可控的 xAI 周期调用后：

- YouTube：频道 ID 缓存后预计 5 次上传列表 + 1 次视频详情，即约 6 个普通配额点；
- AnySearch：1 次能力查询 + 1 次最多 5 意图的批量查询，$0；
- xAI：0 次，$0；
- 不需要 X 信号时，每轮可预期直接 API 美元成本：**$0**；这只是当前工具组合的结果，不是选题优化目标。

如果未来再次人工批准 xAI 调研，必须把本轮 **约 $0.11/次请求** 作为观察到的成本基线，而不是 $0.005；按本轮消耗粗略计算，$5 credit 可覆盖约 44 次同等请求，且实际波动未知。是否调用由“能否回答一个明确且重要的用户问题”决定，不能为了省钱牺牲必要信号，也不能为了追求样本量无目的重复调用。
