# 多活十年 Lab｜公众号视觉与排版系统 V0.3

> 日期：2026-08-03  
> 状态：`Testing / NeedsCreatorReview`  
> 上层视觉锤：暖白纸张感、红笔拆坑、绿笔圈行动、健康功课单  
> 目标：眼睛友好、手机上易读、带有人手做功课的质感，不做花哨模板

## 一、视觉母题

> 城市生活照片 × 编辑部批注系统

画面负责把读者带进真实决策现场，批注系统负责把问题拆清楚。暖白像认真摊开的功课纸，朱红负责拆坑和风险，荧光青绿负责圈出行动和确定信息，墨黑负责正文与证据。

这套系统跨媒介共享的是颜色、动作和“健康功课”识别，不是把同一张卡片硬套到所有媒介。

## 二、公开层与生产层

内部 `Topic ID`、`Content ID`、Claim ID、版本号和工作流状态只用于追踪事实与素材，不得渲染到任何公众可见位置，包括封面、正文、功课单、配图、视频画面、字幕、音频口播和社交平台文案。

`[证据]`、`[拆坑]`、`[风险]`、`[行动]`、`[边界]` 可以作为生产层的语义标记，但公开稿不得直接显示中括号标签。公开层应把它们翻译成自然标题、完整句子、颜色和版式动作。

发布前同时检查可见文字与图片。内部编号可以保留在文件名、目录、素材清单和元数据中。

## 三、色彩

| 角色 | 色值 | 用法 |
|---|---|---|
| 暖白纸 | `#FFFDF5` | 正文背景、功课单底色 |
| 次级纸色 | `#F4F0E6` | 来源区、轻提示底色 |
| 墨黑 | `#282923` | 正文与主要标题 |
| 次级灰 | `#6D716A` | 摘要、图注、来源 |
| 荧光青绿 | `#B7F34A` | 圈行动、标题标记、重点底线；不作小字号正文颜色 |
| 深行动绿 | `#28634B` | 链接、行动提示、深色文字 |
| 朱红 | `#C74638` | 拆坑、风险、否定批注 |
| 淡风险红 | `#F8E7E3` | 风险提示底色 |
| 分隔线 | `#D9D5CA` | 细线和表格边界 |

同一屏最多出现一个荧光重点和一个朱红重点。颜色负责语义，不负责热闹；不能只靠颜色传递必须理解的信息。

## 四、字体与字号

公众号正文不依赖读者设备未必拥有的特殊字体。使用：

```text
-apple-system, BlinkMacSystemFont, "PingFang SC", "Microsoft YaHei", sans-serif
```

| 元素 | 字号 | 行高 | 样式 |
|---|---:|---:|---|
| 平台文章标题 | 微信原生标题栏 | 微信原生 | 不在正文重复一个大标题 |
| 导语／副标题 | 14px | 1.75 | 次级灰；不超过 3 行 |
| 二级标题 | 20px | 1.45 | 700；墨黑；荧光绿手绘感底线 |
| 三级标题 | 17px | 1.6 | 700；深行动绿或朱红批注 |
| 正文 | 17px | 1.85 | 400；墨黑；段落间距 16px |
| 引用／关键判断 | 16px | 1.8 | 左侧 4px 语义色边线 |
| 图注／来源 | 13px | 1.7 | 次级灰 |

正文不使用整段加粗、整段彩色或连续下划线。下划线只给链接；需要强调时，优先加粗一句中的关键词或使用短荧光标记。

## 五、版式组件

### 5.1 开场

- 从正文直接进入场景，不把证据摘要或内部标签顶在第一屏；
- 不重复封面标题；
- 前 2—3 屏避免同时出现多个卡片和装饰；
- 第一屏优先让读者看到具体人物、动作、冲突或一句真正抓人的判断。

### 5.2 标题

- 左对齐，一个标题只承担一个意思；
- 标题应是读者自然会说、单独拿出来也通顺的话；
- 需要主语或对象才能理解时，不得为了短而删掉，例如用“健康项目，值几万块吗？”而不是“几万元，值吗？”；
- 使用荧光青绿粗底线，不使用渐变、阴影、玻璃拟态和悬浮圆角卡片。

### 5.3 语义提示

- 行动：深行动绿边线，暖白或浅绿底；
- 拆坑／风险：朱红边线，淡风险红底；
- 证据：墨黑边线，次级纸色底；
- 边界：灰色边线，明确说明不能推出什么；
- 上述名称只用于生产层。公开层使用自然小标题或完整句子，不显示方括号标签。

### 5.4 健康功课单

每篇核心文章结尾可放一张结构稳定的健康功课单。它既可以是正文中的 HTML 组件，也可以输出为 PNG，方便图文、视频和其他媒介复用。

固定动作：

- 朱红划掉模糊承诺或风险；
- 荧光青绿圈出今天能做的一件事；
- 保留自然的账号署名与来源／边界提示；
- 不公开内部编号、工作流状态、版本号或 Claim ID。

### 5.5 图片

- 封面：输出 2.35:1 主封面和 1:1 安全裁切；中文标题由程序准确叠加；
- 正文按大模块评估配图，不机械按字数插图。一个大模块较长、情绪持续单一或包含抽象关系时，优先安排一张承担明确任务的图片；
- 约 2000—4000 字的长文可以使用“开场场景＋2—4 张模块图＋结尾功课单”，具体数量服从阅读节奏；
- 图片任务至少属于一种：代入真实场景、制造幽默或讽刺情绪、呈现冲突、解释关系、压缩行动；纯装饰图不计入；
- 同一篇优先混合生活场景、原创编辑插画和确定性图表，不连续堆叠同一种卡片；
- 影视剧截图、表情包和网络图片不作为默认素材。只有版权、授权、人物与语境均明确时才可使用；否则用原创场景或编辑插画承接相同情绪；
- 场景图必须注明“示意图”，不得冒充真实机构、人物、产品或采访；
- 证据图、清单和比较优先用确定性图表，不让生图模型生成精确数据和中文文字；
- 除封面外，公众配图右下角统一加入 `多活十年 Lab` 署名。按 375px 正文显示宽度折算后，文字视觉高度不得低于约 14px；右边和下边安全距离不低于图片短边的 4%；必要时使用半透明暖白底保证可读；
- 图片宽度 100%，不使用厚阴影；图注紧跟图片。

## 六、封面模板

- 视觉比例：2.35:1；同时保留 1:1 安全裁切；
- 画面以一个清楚的生活决策瞬间为主，留出大字区；
- 封面短标题不是发布标题的机械截断，应是主语或对象明确、脱离正文也通顺的一句话；
- 建议 8—16 个汉字，最多 3 行；只保留一个核心冲突，不放摘要、论证或成段小字；
- 大字直接进入画面；封面不放 `多活十年 Lab` 文字署名、摘要或其他需要读者费力辨认的小字；不使用大块半透明信息卡遮住场景；
- 使用一个朱红批注动作和一个荧光青绿行动动作；
- 不使用白大褂、医院蓝、黑金抗衰、DNA、胶囊、器官模型、衰老恐惧和不可核验疗效。

## 七、成稿包

每次公众号 Skill 的完整输出包括：

```text
publication/
├── article-publish.md
├── wechat-fragment.html
├── wechat-preview.html
├── cover-2.35x1.jpg
├── cover-1x1.jpg
├── inline-01-scene.jpg
├── homework-card.png
├── visual-manifest.md
└── prompts.md
```

若图片工具可用，直接生成并保存图片；不可用时才退化为提示词包。没有图片不得伪装成完整成稿包。

## 八、跨媒介共享

跨媒介固定共享：暖白纸、墨黑、荧光青绿、朱红、红笔拆坑、绿笔圈行动和健康功课单。不同媒介可以改变画幅、信息密度、节奏、字号和组件形态。

内部 Content ID 负责让生产系统认出“这是同一期内容”，但它不是视觉锤，也不是公众品牌资产。

## 九、可读性与检查

- 以 375px 手机宽度预览；
- 正文保持 17px、1.85 行高和足够段间距；
- 荧光色只作底线或底色，文字仍用墨黑；
- 长链接、图片和代码不得横向溢出；
- 检查封面问句是否主语明确，截去正文语境后仍然通顺；
- 搜索并确认公开 Markdown、HTML 和图片可见文字中没有内部编号、版本状态和方括号语义标签；
- 发布前在微信后台手机预览一次，检查粘贴后样式、图片、标题裁切和深浅模式表现。

## 十、暂不自动化

- 不保存公众号 AppID、AppSecret 或第三方排版服务密钥；
- 不自动上传素材、创建草稿或发布；
- 本地 HTML 只是可复制排版稿。微信会过滤外部图片 URL，最终图片必须在平台内上传或经官方接口处理；
- 视觉通过创作者确认、G2/G3 内容检查和 G4 发布检查后才可对外使用。
