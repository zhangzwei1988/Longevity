# 选题 Agent 输入收件箱

> 状态：临时输入区，不是项目事实源，也不是 Agent 长期规范  
> 更新日期：2026-08-02

这里仅保存需要跨对话继续处理的零散输入，例如：选题灵感、账号链接、用户反馈摘要、希望关注的问题和待核验信息。

不在这里保存：

- 完整聊天记录；
- 已经确认的长期规则；
- 候选选题和评分结果；
- API 费用和运行日志；
- 可识别个人病历、联系方式或不必要的敏感健康信息。

## 状态

- `pending`：尚未拆解；
- `extracted`：已提炼为选题输入或学习记录；
- `discarded`：不进入系统，并保留简短原因；
- `expired`：因时效失效。

## 待处理

当前无待处理项。

```text
Input ID：IN-YYYYMMDD-01
日期：
类型：灵感／链接／账号／用户反馈／范围调整／其他

敏感性：普通／需去标识化／不得落盘
状态：pending
处理结果：
```
