# 多活十年 Lab｜小红书图文视觉系统 V0.1

> 日期：2026-08-07  
> 状态：首轮设计试运行；待创作者基于真实成品确认  
> 适用范围：多活十年 Lab 小红书图文  
> 上层依据：[账号定义包](account-definition-pack.md)、[写作 Agent V0](writing-agent-v0.md)、[内容 Harness 纲领](../docs/06-content-harness-charter.md)

## 一、目标

把已锁定的统一内容包和已确认的叙事底稿转译为小红书原生的 8—9 页图文。成品应当精致、有生活感、值得收藏，同时保留证据、边界和真人表达的自然手感。

图文不承担重新研究、补造事实、复制公众号长文或自动发布的职责。

## 二、参考样本与证据范围

本版由创作者提供四个小红书样本：

1. 刘铁柱《Anthropic 官方教 Agent 记忆：4 个 md 就够了》
2. Ethan.AI 商业分析实战《Claude 必装 11 个配置详解（下）》
3. 中信出版通识教育《“童年富裕症”正在制造新一代的“空心娃”》
4. AIGC 之眼《Claude Code 究竟该咋用？》

只把这些样本当作视觉偏好证据，不把其内容事实、账号身份或表现数据写入健年的规则。

本轮公开读取拿到了样本 2、3 的完整图册，以及样本 1、4 的标题和正文。没有看到的页面不作视觉推断。可确认的参考价值如下：

- 样本 2：编辑部感、强层级、稳定页眉、克制配色和高信息密度；不足是连续页面过于同构。
- 样本 3：实拍书页、局部遮挡、荧光标记、贴纸、手写批注和不完全对齐，具有真实整理痕迹；不足是背景复杂时可能影响文字可读性。
- 样本 1、4：正文显示其使用完整拆解、清单和路径式结构，可用于分页节奏参考，不作为视觉样式证据。

## 三、视觉命题

沿用账号视觉方向：

> 明亮的城市生活感 × 克制的实验记录感

小红书版本增加一个媒介特征：

> 有人真正看过、想过、划过重点的编辑手感

它不等于随意。统一来自字体、语义色、署名、页码和判断方式；自然感来自图片裁切、材料切换、批注位置、留白和页面节奏的变化。

## 四、稳定视觉元素

### 4.1 色彩

| 用途 | 色值 | 说明 |
|---|---|---|
| 纸张底色 | `#FFF9EF` | 温暖、轻盈，避免医院白 |
| 正文墨色 | `#252821` | 主要文字与轮廓 |
| 低权重灰 | `#6D716A` | 限制、来源、注释 |
| 行动绿 | `#B7F34A` | 可以做、可执行动作 |
| 判断青 | `#28634B` | 证据、判断、稳定信息 |
| 拆坑红 | `#C74638` | 风险、停顿、需要警惕 |
| 批注黄 | `#F3D75A` | 荧光笔和局部提示 |

一页通常只使用一个主强调色。不能为了“丰富”把所有颜色同时铺满。

### 4.2 字体与文字

- 主要中文使用苹方或同类清晰黑体。
- 手写字体只用于短批注、提问或一句收口，不能承载关键事实和长段正文。
- 精确中文、数字、来源、清单和限制必须确定性排版，不交给生图模型。
- 不用故意错别字、混乱标点或随机字距制造人工感。

### 4.3 固定识别

- 右下角或底部使用轻量署名“多活十年 Lab”。
- 使用 `01/09` 形式的页码，但不让页码成为视觉主体。
- “已知／未知”“证据／经验”“可以做／需要确认”采用稳定语义色，不公开内部方括号标签。

## 五、页面材料库

每组至少使用三种页面材料，并让相邻页面发生变化：

1. **生活场景页**：真实授权照片或无文字 AI 合成场景，承担当下时刻和情绪。
2. **编辑信息页**：大标题、短正文、强留白和一处下划线，承担核心判断。
3. **纸张拼贴页**：便签、纸边、轻微旋转和局部遮挡，承担人的整理痕迹。
4. **对话冲突页**：两种说法或前后错位，承担叙事高峰。
5. **框架页**：2—4 个组成部分，承担可收藏结构。
6. **行动清单页**：明确的一步或少量问题，承担保存和执行价值。

不连续使用三张同结构卡片；不把所有页面做成相同圆角、相同标题位置和相同三栏网格。

## 六、默认 9 页节奏

默认节奏只是一套起点，不是固定模板：

1. 封面：处境或冲突＋明确获得感；
2. 场景：把用户带入一个具体时刻；
3. 框架：尽早交付本期唯一判断路径；
4. 拆解一：推进第一个关键问题；
5. 拆解二：推进第二个关键问题；
6. 高峰：使用现实冲突、错位或对话；
7. 拆解三／四：补齐责任、限制或容易漏掉的一环；
8. 收藏页：把框架变成能直接使用的清单；
9. 峰终收口：记忆判断、边界和自然互动问题。

内容能在 8 页自然结束时不补空页。任何数量承诺都必须与实际页面内容一致。

## 七、构图与平衡

- 画布默认 `1080 × 1440`，比例 `3:4`；发布前复核当日平台规格。
- 四边保留安全区，封面标题避免紧贴头像、页码和界面遮挡区域。
- 每页只有一个主视觉重心；次要说明以大小、颜色和位置降权。
- 不要求几何居中，但要保持视觉重量平衡。上半部使用大标题时，下半部用图片、色块或留白承接。
- 背景复杂时增加局部遮罩或纸张层，不直接把小字压在纹理上。
- 每页正文控制在手机一眼可扫读的范围，解释不下时删减支线或增加页面，不缩成小字墙。

## 八、AI 底图与插画

允许使用 AI 生成的主题底图或插画，但只生成视觉层：

- 不要求模型生成中文、数字、Logo、论文封面、证书或合同内容；
- 不出现可识别机构、产品、医生、病历或真实个人信息；
- 合成消费场景必须记录其合成性质，不冒充真实案例；
- 保存生成提示词、原图、裁切、调色和叠字记录；
- 发布时根据平台当日功能和规则完成 AI 标识，并由 G4 检查。

## 九、输出与审核

每期输出：

- 8—9 张 `1080 × 1440` PNG；
- 对应可编辑 SVG 与 HTML 总览；
- 封面标题、发布标题、正文、互动问题和标签；
- 图片 Alt、素材来源、AI 说明和视觉资产清单；
- 事实一致性、文字溢出、视觉平衡、隐私、版权和发布边界检查。

正式发布仍执行 G4 人工门。未锁定输入只允许设计试作，所有图片必须带“设计试稿 · 不可发布”。

## 十、首轮待验证

- 目标用户更偏好生活场景还是编辑信息密度；
- 手写批注的使用量是否自然；
- 每页文字量与收藏价值的平衡；
- 封面“问题型”与“明确获得型”的停留差异；
- 9 页是否比 8 页更完整，还是造成重复；
- 人工修改最多的是标题、分页、配色、底图还是收口。

前 3—5 个真实主题只记录反馈，不因一次主观偏好或表现数据直接改写长期规则。
