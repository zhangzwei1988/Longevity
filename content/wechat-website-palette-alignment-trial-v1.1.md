# 健年官网 × 公众号配色对齐试验 V1.1

> 日期：2026-08-03  
> 状态：`Testing / NeedsCreatorReview`  
> 适用对象：公众号 V0.12 配色对照稿  
> 当前正式规范：`content/wechat-publication-standard-v1.0.md`，本文件尚未替代它

## 一、这次要验证什么

官网已经形成一套比较稳定、也更接近健年母品牌的颜色关系：暖纸色承接长期阅读，深绿负责品牌与可信感，橙色负责把关键动作从页面里挑出来。

公众号不应另起一套互不相干的颜色，但也不能机械复制官网。官网主要负责品牌叙事和空间感；公众号主要负责连续阅读、证据核对、风险停顿和行动提示。因此，本轮采用：

> 官网提供基础色盘，公众号在基础色盘上增加少量渠道语义。

本轮只改颜色，不同时迁移官网的宋体标题、轨道、路径、圆形装置或网页卡片结构。这样可以单独判断：新色盘本身是否让公众号更像健年，同时保持原有阅读效率。

## 二、基础色盘与公众号角色

| 官网色彩 | 色值 | 公众号角色 |
|---|---:|---|
| 纸色 | `#F5F1E8` | 页面底色、图片纸张底色 |
| 深一层纸色 | `#EAE3D5` | 来源附录、证据核对、次级信息区 |
| 墨色 | `#152B24` | 正文、标题、必要高对比文字 |
| 品牌绿 | `#1E493C` | 可执行行动、链接、稳定判断 |
| 深绿 | `#0F3028` | 强品牌面、深色强调的备用色 |
| 鼠尾草绿 | `#ADC3B5` | 边界、证据、次级线条 |
| 薄荷绿 | `#DFE9DF` | 行动提示的浅背景 |
| 橙色 | `#E86F3E` | 编辑批注、暂停、拆坑和标题实线 |
| 柔橙 | `#F6C5AA` | 橙色提示的辅助色；大面积使用时再降低饱和度 |

公众号额外保留一个可读性中性色：

- 次级文字 `#56665F`：用于署名、附录和次级说明；在 `#EAE3D5` 上对比度约为 4.75:1。
- 分隔线 `#C7C8BE`：只负责结构，不承担结论。
- 暖橙浅底 `#F9E1D2`：由官网柔橙继续减弱，用于暂停、记录和批注背景。

## 三、语义映射

| 内容动作 | V1.0 | V1.1 试验 |
|---|---|---|
| 正文与标题 | 中性墨黑 | 官网墨绿黑 `#152B24` |
| 奇数二级标题实线 | 荧光青绿 | 官网橙 `#E86F3E` |
| 偶数二级标题虚线 | 次级墨灰 | 鼠尾草绿 `#ADC3B5` |
| 行动／可以做 | 深行动绿＋浅绿底 | 品牌绿 `#1E493C`＋薄荷绿 `#DFE9DF` |
| 证据／边界核对 | 墨灰虚线＋次级纸色 | 品牌墨色或鼠尾草绿虚线＋深一层纸色 |
| 拆坑／先停一下 | 朱红＋淡风险红 | 官网橙＋暖橙浅底 |
| 真实高风险或禁止 | 朱红 | 暂时仍保留朱红，只在确有风险时使用 |
| 图片署名 | 中性墨灰 | 次级绿灰 `#56665F` |

关键判断：橙色是“编辑拿红笔提醒你看这里”，不是“危险警报”；真正的医学风险、禁止事项和强烈中止仍可使用独立朱红。这样既保留“红笔拆坑、绿笔圈行动”的动作感，又不会让每一次批注都像系统报错。

## 四、本轮不改什么

- 不改文章内容、标题结构、emoji 数量、加粗密度和图片位置；
- 不改官网内容、网页布局或现有页面；
- 不把官网的衬线字体、轨道、圆环和页面卡片直接搬进公众号；
- 不改变医疗、证据、隐私和来源附录边界；
- 不更新正式规范和已安装 Skill。

## 五、通过条件

V0.12 只有同时满足以下条件，才建议把本文件合并为公众号正式规范 V1.1：

1. 一眼看上去与健年官网属于同一品牌，而不是两个模板；
2. 长文阅读没有因为纸色或深绿而变暗、变闷；
3. 橙色批注与绿色行动能被读者自然区分；
4. 来源附录仍然降权，但必要文字对比度不低于 4.5:1；
5. 健康功课单仍有“人手做功课”的感觉，没有变成普通企业信息图；
6. 创作者在 V0.11 与 V0.12 对照后明确批准。

未通过时，V1.0 继续有效，V0.12 只作为一次有记录的配色试验。
