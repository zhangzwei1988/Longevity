# 选题 Agent 学习与规则变更记录

> 状态：学习中转区，不是聊天记录，不直接替代系统契约  
> 更新日期：2026-09-24

本文件只保存从真实运行和创作者反馈中提炼出的规则变化。完整对话不复制到这里；每条记录必须说明问题、规则变化、状态和最终合并位置。

## 状态

- `proposed`：已提炼，尚未确认；
- `accepted`：创作者已确认，等待写入固定系统；
- `merged`：已写入固定系统；
- `validated`：后续真实运行证明有效；
- `reverted`：已撤销，并保留原因。

## L-20260802-01：用户场景与品牌信任优先

- 来源：首轮 G1 全部退回后的创作者反馈；
- 发现：首轮候选偏内部分类、证据结构和成本控制，用户难以认出自己的具体处境；
- 规则变化：把场景自我识别、切身利益、具体帮助和品牌信任放在评分前部；成本退出内容价值评分，只保留预算护栏；
- 状态：`validated`；第二版选题方向获得创作者认可；
- 合并位置：[选题 Agent V0](topic-agent-v0.md)“首要目标”“用户场景门”“评分与退回”；
- 影响产出：首轮五项保留为 `changes_requested`，第二版按用户场景重构。

## L-20260802-02：主标题与内部副标题分层

- 来源：第二版 G1 标题反馈；
- 发现：用户场景正确，但标题承载过多背景、利益和方法，阅读负担过大；
- 规则变化：对外使用短主标题，内部副标题保存完整场景、利益和内容承诺；主标题默认 8—16 个汉字，原则上不超过 18 个；
- 状态：`merged`，仍需通过真实发布验证；
- 合并位置：[选题 Agent V0](topic-agent-v0.md)“主副标题结构与三秒测试”和[选题任务书](../templates/topic-brief.md)；
- 影响产出：第二版候选改为短主标题加内部副标题。

## L-20260802-03：标题必须对准用户原生问题

- 来源：短标题再次修改时的创作者反馈；
- 发现：机械删字虽然缩短标题，却把 Agent 的中间步骤误写成用户目的；
- 规则变化：标题生成前先补完“我现在最想知道的是……”，主标题必须像用户会自然说、问或搜索的话，并对准最终问题或希望达到的结果；
- 状态：`merged`，仍需通过真实发布验证；
- 合并位置：[选题 Agent V0](topic-agent-v0.md)“主副标题结构与三秒测试”和[选题任务书](../templates/topic-brief.md)；
- 影响产出：体检、医生意见冲突和专家门诊三个标题及内容交付重新对齐。

## L-20260802-04：输入、学习、系统和产出分离

- 来源：创作者对 Agent 长期可理解性和未来 Harness 组合方式的明确要求；
- 发现：对话反馈、固定规范和单轮运行结果如果写在同一处，会导致事实边界不清，也无法解释系统为何改变；
- 规则变化：建立输入收件箱、学习中转、固定系统、运行产出四个区域；任何长期规则变化必须先形成学习记录，再合并进系统；
- 状态：`merged`；
- 合并位置：[选题 Agent V0](topic-agent-v0.md)“四个信息区域”和[Harness 建设纲领](../docs/06-content-harness-charter.md)；
- 验证方式：后续两轮检查是否仍有聊天原文、单轮候选或费用账单混入系统契约。

## L-20260802-05：评论区作为独立需求信号层

- 来源：创作者明确指出评论区问题具有高价值，很多选题来自用户真实反馈；
- 发现：只看视频标题和播放量会看到创作者想讲什么，却看不到用户听完后仍卡在哪里；评论能补充用户原生语言、具体执行障碍和未被满足的问题；
- 规则变化：正式增加评论区信号层；高互动与最新评论并行抽样；只沉淀匿名化问题簇，不保存用户名、评论 ID 和完整个人健康叙事；评论不承担医学证明；
- 状态：`merged`，第二批开始验证；
- 合并位置：[选题 Agent V0](topic-agent-v0.md)“评论区信号”、[来源登记](topic-source-registry.md)“YouTube 评论抽样”和[选题任务书](../templates/topic-brief.md)；
- 验证方式：检查评论是否带来比内容标题更具体的场景，入围候选是否仍能通过目标用户、证据和专业边界三道门。

## L-20260802-06：标题不仅要清楚，还要让用户多看一眼

- 来源：第二批 G1 的创作者反馈；
- 发现：第二批选题方向总体成立，但“包装食品怎么选、健康建议怎么选”等表述只是准确复述主题，没有充分呈现用户的现实限制、切身利益和未解决矛盾；
- 规则变化：在三秒读懂之外增加“多看一眼测试”；标题至少呈现未解决的决定、现实限制、利益差或认知冲突之一，同时禁止靠扩大范围、隐藏信息或医学暗示制造吸引力；
- 状态：`merged`，仍需通过真实发布验证；
- 合并位置：[选题 Agent V0](topic-agent-v0.md)“主副标题结构、三秒测试与多看一眼测试”和[选题任务书](../templates/topic-brief.md)；
- 影响产出：第二批五项重新校准标题，其中补剂选题连同目标场景和内容交付一起重构；运动选题扩大到“不爱运动”时，明确新增范围仍需验证。

## L-20260802-07：不把健康行业缩写当作用户语言

- 来源：创作者对“不爱运动，怎么开始护心”的反馈；
- 发现：“护心”虽然简短，但更像健康内容行业的压缩词，普通用户不常这样描述自己的需要，也缺少“保护心脏”的直接体感；
- 规则变化：标题优先使用目标用户日常会说、会问的完整表达；行业缩写、项目术语和为了字数生造的短词必须通过真实用户语言检查；
- 状态：`merged`，仍需通过真实发布验证；
- 合并位置：[选题 Agent V0](topic-agent-v0.md)“当前固定经验基线”和[选题任务书](../templates/topic-brief.md)；
- 影响产出：第二批第四项改为“不爱运动，怎么开始保护心脏？”。

## L-20260802-08：一个核心选题生成多媒介标题变体

- 来源：创作者计划将同一主题发布为公众号长文、小红书或公众号图文、短视频和播客；
- 发现：不同媒介的用户状态、阅读时间和标题任务不同，机械共用一个标题会牺牲平台原生表达；但每个平台重新决定主题会造成事实和承诺漂移；
- 规则变化：一个 Topic ID 保留一个核心用户问题、内容承诺和边界；G1 可记录初步媒介方向，G3 锁定统一内容包后再生成渠道标题，G4 人工核对标题、封面、开场和正文一致性；
- 状态：`validated`（方法层创作者人工验证）；尚未经过真实发布数据验证；
- 合并位置：[核心选题与媒介标题变体规则](topic-channel-title-rules.md)、[选题 Agent V0](topic-agent-v0.md)“当前固定经验基线”和[选题任务书](../templates/topic-brief.md)；
- 验证证据：`T-20260802-R1-05`“几万元的健康项目，值吗？”完成媒介标题试作，创作者确认当前版本总体满意；核心题、长文、图文、短视频和播客的分工方式保留；
- 后续验证：同一主题发布后分别记录各媒介的点击、停留、收藏、完播、听完、评论和有效对话，不跨平台混算。

## L-20260817-09：从知识增量转向当前约束下的较优选择

- 来源：创作者复看前两批选题后的定位反馈；
- 发现：现有候选虽然增加了用户场景和切身利益，内容任务仍常落在“解释知识、教几个方法”，没有充分帮助目标用户在现实经济条件和生活约束下配置健康投入；
- 规则变化：增加“非纯科普与资源配置门”；候选必须说明用户正在分配的稀缺资源、现实约束、选择集合、总成本、机会成本和可推进的决定；评分新增“当下决策与资源配置价值”；明确性价比不等于最低价，“最优解”只表示基于现有信息、可以随条件变化而复审的当前较优选择；
- 人性要求：除理性收益外，候选还要识别用户对安心、掌控、减负、尊严、减少内疚或避免后悔的需要；专业证据作为后台支撑，不把知识讲解本身当作默认内容任务；
- 医疗边界：涉及诊断、治疗、检查、用药和康复时，只提供通用判断框架、信息整理和专业沟通准备，不替用户作个体医学取舍；
- 状态：`merged`，等待下一轮真实选题验证；
- 合并位置：[选题 Agent V0](topic-agent-v0.md)“首要目标”“候选选题固定输出”“非纯科普与资源配置门”“评分与退回”“当前固定经验基线”及[选题任务书](../templates/topic-brief.md)；
- 后续验证：用第三批候选检查泛科普题是否被降级、入围题能否说明具体取舍和机会成本，以及标题与正文是否仍保持轻松、自然、不制造焦虑。

## L-20260924-10：从日常场景中的社会矛盾发现选题

- 来源：创作者连续反馈选题过度集中于医学、父母和体检，并确认应寻找与健康寿命相关、社会话题性强、用户已有感受却难以表述的真实困境；
- 发现：仅把专业知识套进一个日常场景，仍会产出纯科普；仅有尖锐标题却没有可交付的帮助，也只是情绪表达；
- 规则变化：先观察具体现场里的两难关系，如身体与个人时间、工作与恢复、便利与长期投入、自主感与健康数据、社交归属与身体边界。用用户的自然语言说出尚未被说清的困境，再确认本期能帮助完成什么取舍、协商或减负。社会讨论是需求信号，可靠资料是后续解题材料，二者不互相替代；
- 范围：优先扩展当前账号宪法中的“忙碌人群的真实健康困境”，但不把上述矛盾类型变成固定配额或永久选题清单；不排斥确有价值的体检、就医或父母主题；
- 状态：`merged`（发现方法已获创作者方向认可；本轮标题和选题尚待人工验证）；
- 合并位置：[选题 Agent V0](topic-agent-v0.md)“固定输入”“社会矛盾发现门”“当前固定经验基线”及[选题任务书](../templates/topic-brief.md)；
- 后续验证：请创作者判断标题是否让人认出自己的隐性困境，内容承诺是否专业、扎实而非说教，是否真的扩大了日常场景覆盖。

## L-20260924-11：成熟目标用户筛选与完整冲突优先于短标题

- 来源：创作者对社会矛盾小样的反馈，明确目标用户为 35—55 岁、有一定财力、社会经验与地位的人；认可发现方向，但认为部分题目过于初级，标题短却没有点明冲突、价值或探索欲；
- 发现：公开讨论者与目标用户不自动重合；“会做饭吗、怎么拒酒”等入门问题即使有人讨论，目标用户也可能已有解法。原 8—16 字和 18 字护栏被机械执行后，标题只剩模糊感叹，真正的两难留在内部副标题里；
- 规则变化：新增“成熟用户增量价值门”：先问有经验、有资源、有一定决策权的用户为何仍无法靠常识、购买或委托解决；若答案只是初级技巧，则淘汰或降为一般内容。标题先写清场景中的双方拉扯、切身代价与值得探索的问题，再压缩到最短但仍完整的长度；G1 核心标题不设 18 字硬上限，媒介封面短版后续另做；
- 来源限制：V2EX 等非目标人群社区只可发现语言和问题假设；目标用户匹配度未由访谈、评论或行为证实前，不标成已验证需求，不以互动量替代匹配度；
- 状态：`merged`（筛题与标题方法已获创作者明确纠偏；本轮改写标题仍待人工验证）；
- 合并位置：[选题 Agent V0](topic-agent-v0.md)“成熟目标用户增量价值门”“主副标题结构”与“当前固定经验基线”、[选题任务书](../templates/topic-brief.md)、[媒介标题变体规则](topic-channel-title-rules.md)；
- 后续验证：用目标用户的一手反馈检查题目是否越过初级常识层，再分别测试核心标题的清楚度、停留欲和正文兑现度。
