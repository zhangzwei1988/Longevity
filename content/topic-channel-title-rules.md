# 核心选题与媒介标题变体规则

> 版本：V0.2  
> 日期：2026-08-02  
> 状态：固定系统规范；方法已通过一次创作者人工验证，发布效果尚未验证

## 一、基本关系

同一个选题可以、也应该针对不同媒介生成标题变体，但它们必须共用一个 Topic ID、一个用户问题和一个内容承诺。

```text
核心选题
  → 用户问题、切身利益、内容承诺和边界
  → 统一内容包锁定
  → 公众号／图文／短视频／播客标题变体
```

媒介标题变体是不同入口，不是四个新选题。可以改变长度、节奏、信息顺序和开场角度，不能擅自改变：

- 目标用户正在解决的问题；
- 正文能够兑现的具体帮助；
- 核心事实、证据等级和不确定性；
- 医疗、资质和隐私边界；
- 是否需要合格专业人员编写或审核。

如果某个媒介标题改变了核心结论、适用人群或承诺，应回到 G1／G2 重新检查，而不是把它当成普通文案优化。

## 二、生成时点

- **G1 选题阶段**：确定核心选题名、内部副标题和适配媒介；可以写初步变体方向，但不必为每个候选生产完整标题组。
- **G3 统一内容包锁定后**：根据已经确认的事实、结论和限制生成各媒介公开标题。
- **G4 发布前**：人工检查标题、封面、开场和正文是否承诺一致。

这样既允许在选题时判断媒介潜力，也避免证据尚未完成时先写出正文无法兑现的标题。

## 三、不同媒介的标题任务

以下字数是创作起点，不是平台技术上限。真实发布数据积累后再调整。

G1 的核心标题不受封面短标题字数约束：先把成熟目标用户的完整困境、利益冲突和阅读价值说清，再按媒介位置做精简变体。若短版失去冲突，改由封面标题与发布标题／口播共同承担信息，不把模糊短句当作合格标题。

| 媒介 | 用户状态 | 标题首要任务 | 建议结构与长度 |
|---|---|---|---|
| 公众号长文 | 愿意投入数分钟阅读，重视逻辑与可信度 | 把问题、冲突和阅读价值交代完整 | 约 16—28 个汉字；场景＋核心问题，或冲突＋判断价值 |
| 小红书图文 | 快速扫封面，寻找“和我有关”及可收藏内容 | 先让用户认出自己的处境，再给一个明确获得感 | 封面约 8—14 字；发布标题约 12—22 字，可补搜索词 |
| 公众号轻图文／卡片 | 来自订阅、转发或社群，阅读时间比长文短 | 用一个问题或一张可保存的框架建立价值 | 头图约 8—14 字；推送标题约 12—22 字 |
| 短视频 | 滑动速度快，先听到或看到一句话 | 标题、封面和前三秒共同完成停留，不让标题独自解释全部背景 | 封面约 6—12 字；发布标题约 10—20 字；另写一句口播开场 |
| 播客 | 选择成本高但陪伴时间长，重视主题与人格 | 清楚说明值得陪伴讨论的问题，并保留长期搜索价值 | 约 14—26 个汉字；主题＋冲突／思考问题，可配副标题 |

## 四、稳定生成方法

### 第一步：冻结核心卡

生成任何媒介标题前，先写清五项不变量：

1. 用户正处在哪个具体时刻；
2. 他最怕损失、做错或错过什么；
3. 他真正要完成的决定或任务；
4. 内容能够交付什么具体帮助；
5. 内容不能替用户判断什么。

五项没有写清，不进入媒介变体。

### 第二步：决定媒介任务

先问“这个位置负责什么”，再写字：

- 长文标题负责“问题＋完整阅读价值”；
- 图文封面负责停留，发布标题负责说明、搜索和收藏价值；
- 短视频封面负责冲突，发布标题负责补充获得感，前三秒负责进入现场；
- 播客标题负责提出值得长时间陪伴讨论的问题，副标题说明展开路径。

### 第三步：先判断是否需要改题

媒介变体不是为了变化而变化。核心标题如果已经适合某个位置，可以直接复用；只有当用户状态、可用空间或媒介任务不同，才调整长度、顺序和角度。

### 第四步：生成“标题组合”而不是孤立标题

- 公众号长文：公开标题；
- 小红书图文：封面标题＋发布标题；
- 公众号轻图文：头图标题＋推送标题；
- 短视频：封面标题＋发布标题＋前三秒口播＋承接句；
- 播客：单集标题＋副标题／简介入口。

同一媒介里的多个位置应分工，不必重复同一句话。

### 第五步：立即兑现钩子

标题或开场打断用户熟悉动作后，下一句必须尽快进入正文承诺。不能只说“先别急”“真相没那么简单”，却迟迟不给判断路径。

### 第六步：做一致性检查

逐项对照核心卡：有没有扩大人群、夸大结论、增加数字承诺、删除关键限制或改变最终导向。任何一项发生变化，都不是普通改标题，必须回到相应关卡检查。

## 五、各媒介不能简单复制什么

### 公众号长文

- 不能像论文题目一样堆满概念；
- 可以比封面标题多交代一层场景和判断价值；
- 不能用长标题掩盖正文没有明确答案。

### 小红书与公众号图文

- 封面标题和发布标题可以不同：封面负责停留，发布标题负责说明与搜索；
- 图文应围绕一个可快速理解、收藏或转发的框架，不是长文截图；
- “清单、步骤、几个问题”等数量承诺，必须与最终内容完全一致。

### 短视频

- 封面、发布标题和口播第一句分工，不必三处重复同一句话；
- 前三秒可以把具体冲突说得更口语，但不能比正文承诺更大；
- 不能为了停留率删掉会改变结论性质的适用范围。

### 播客

- 标题可以容纳更多思考感和陪伴感，不必照搬短视频式钩子；
- 不能只写抽象栏目名，必须让新听众知道本期讨论什么；
- 播客不是朗读公众号文章，标题也应反映谈话过程或核心追问。

## 六、一个核心选题的示例

以下只示范媒介分工，不是已批准的发布标题。

核心选题：**健康建议各说各话，该信谁？**

| 位置 | 示例变体 |
|---|---|
| 公众号长文 | 网上健康建议互相矛盾时，普通人到底该相信谁？ |
| 小红书封面 | 健康建议，到底信谁？ |
| 小红书发布标题 | 健康博主各说各话，我到底该怎么判断？ |
| 公众号轻图文头图 | 说法相反，先别急着站队 |
| 短视频封面 | 到底该信谁？ |
| 短视频口播开场 | 一个说东，一个说西，单独听都像有道理，你到底信谁？ |
| 播客单集标题 | 当健康建议互相冲突：我们到底在相信什么？ |

## 七、共用检查

每个媒介版本都必须回答：

1. 目标用户能否立即判断“这和我有关”？
2. 标题制造的未解问题是否真实存在，而不是故意藏答案？
3. 标题、封面和开场是否由正文完整兑现？
4. 是否把内部词、专业词或健康营销缩写误当成用户语言？
5. 是否因为换媒介而扩大了适用人群、医学结论或效果承诺？
6. 不看其他媒介版本，这个标题是否仍然自然、完整？

各媒介发布后的点击、停留、收藏、完播、听完、评论和有效对话应分别记录，不能用一个平台的数据证明所有标题变体都有效。

## 八、首次人工验证

`T-20260802-R1-05`“几万元的健康项目，值吗？”完成了第一轮媒介变体试作，创作者确认当前版本总体满意。试作验证了以下方法：

1. 一个足够强的核心标题可以直接复用于小红书封面，不要求每个平台强行改写；
2. 公众号长文适合在核心冲突后补充明确的阅读价值；
3. 图文需要把封面停留与发布标题的信息、搜索和收藏任务拆开；
4. 短视频应把封面、发布标题、前三秒和承接句作为一组设计；
5. 播客可以把一次购买决定上升为价值、信任和责任的长期讨论，但不能改变事实边界；
6. “4 件事”等数字承诺只能在统一内容包确认数量后用于正式发布。

完整试作见[「几万元的健康项目，值吗？」媒介标题变体](topic-channel-title-trial-T-20260802-R1-05.md)。这次确认是**方法层人工验证**，不代表该选题通过 G1，也不代表任何媒介标题已经通过真实发布数据验证。
