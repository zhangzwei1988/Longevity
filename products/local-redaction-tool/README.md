# 健年本地病历脱敏工具

> 状态：产品 0 号构想，暂不进入开发。

## 产品目的

让用户在把健康资料交给健年前，先在自己的电脑上删除姓名、电话、身份证号、病历号等身份信息。它是降低首次提交阻力的免费信任工具，不是当前主要收入来源。

## 核心承诺

- 原始文件不离开用户电脑；
- 识别、遮盖和导出均在本地完成；
- 不上传、不统计、不远程调用模型；
- 用户只得到一个新的脱敏副本，原文件保持不变；
- 用户必须在导出前人工复核。

## 不能只做“马赛克”

安全输出需要永久删除或覆盖底层内容，同时清除：

- PDF OCR 文字层；
- 元数据、批注、图层和附件；
- 图片 EXIF、定位和设备信息；
- 二维码、条形码、签名和人脸；
- 文件名中的身份信息。

处理后的资料仍可能通过医院、日期、年龄和罕见情况组合重新识别，因此只能承诺降低风险，不能轻易宣称“完全匿名”。

## 建议的 V1 范围

- 只支持 JPG、PNG 和常见 PDF；
- 所有模型、字体和资源随软件本地提供；
- 本地 OCR 标出疑似敏感区域；
- 用户手动增删和确认遮盖区域；
- 重新渲染生成无隐藏文字层的新文件；
- 清除元数据、批注、附件和缩略信息；
- 输出前做本地复检并生成验证摘要；
- 只提供“保存到本地”，不提供自动发送或上传。

第一版不支持 DICOM 医学影像，也不承诺自动识别率达到 100%。

## 进入开发的门槛

至少满足以下条件后再开发：

1. 在未来十年健康盘点招募中，隐私顾虑确实导致明显流失；
2. 至少 10 位目标用户愿意实际使用；
3. 现有可信离线工具无法用简单教程解决；
4. 已完成安全设计、威胁模型和独立复检方案；
5. 工具开发不会延误首个付费产品验证。
