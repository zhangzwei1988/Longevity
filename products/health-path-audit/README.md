# 健年健康路径审计创始版

## 产品一句话

面向已经为一个健康问题投入很多、却仍不知道下一步该做什么的人，整理过去的检查、建议、产品和花费，识别路径中的重复、缺口与不可评估之处，形成一张下一步决策地图。

## 适合谁

- 有一个明确、持续困扰自己的主要健康问题；
- 过去一年尝试过多种解决方案；
- 愿意如实整理投入、过程和结果；
- 希望在下一次消费或就医前看清路径；
- 接受本服务不提供诊断和治疗。

## 暂不适合谁

- 出现急症、危险信号或需要立即就医的人；
- 只想获得具体药物、补剂或治疗处方的人；
- 希望获得“根治保证”的人；
- 不愿提供完成审计所需的基本事实，或要求无限期咨询的人。

## 创始版输入

以“一个主要问题”为限：

- 问题出现和变化的时间线；
- 做过的检查和获得的专业意见；
- 使用过的产品、设备、课程、机构和大致花费；
- 每项尝试的目标、频率、持续时间和主观效果；
- 用户最希望做出的三个决定。

只收集完成审计必要的资料。用户应优先提交脱敏副本，不收集身份证号码等无关信息。

## 创始版交付

- 6—10 页健康路径审计报告；
- 1 页路径地图；
- 过去投入与解决方案分类；
- 重复项、缺口和“无法判断有效”的原因；
- 供下一位医生或专业人员确认的问题清单；
- 未来 30 天最重要的 3 个决定；
- 一次 45 分钟线上交付沟通。

## 不交付

- 疾病诊断；
- 个体化处方或治疗方案；
- 停药、换药或调整剂量建议；
- 对某项治疗的保证；
- 无限期答疑与陪伴。

## 创始版实验

- 名额：5 人；
- 价格假设：999 元/人；
- 目标：验证用户是否愿意为“路径清晰度”付费；
- 每例交付后必须访谈并记录实际工时、最有价值部分、未解决问题和转介绍意愿。

## 成功标准

首轮结束时至少满足三项，才考虑继续标准化：

- 5 个名额中至少 3 个为真实付费；
- 至少 3 位用户能明确说出一个因此改变的决定；
- 至少 2 位愿意主动推荐类似用户；
- 交付范围能控制在可接受的工时内；
- 没有依赖越界医学判断才能产生价值。
