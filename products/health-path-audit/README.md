# 健年健康投入复盘｜首批体验版

> 用户看到的商品名：健年健康投入复盘
> 内部使用的方法名：健康路径审计

## 产品一句话

把你过去一年为健康买过的、做过的、被建议过的方案放到一张图上，帮你看清哪些信息还缺、哪些投入无法验证，以及下一步应该先向谁确认什么。

传播钩子：

> 健康上花了这么多钱，为什么还是不知道下一步？

辅助解释：

> 如果你已经尝试了很多方法，却仍不知道下一步该做什么，我们帮你把过去的健康投入完整盘一遍。

## 适合谁

- 有一个明确的非诊疗目标，例如复盘健康消费、改善生活方式执行，或准备下一次就医；
- 过去一年尝试过多种健康产品、生活方式方案或非处方服务；
- 愿意如实整理投入、过程和结果；
- 希望在下一次消费或就医前看清路径；
- 接受本服务不判断疾病，也不提供诊断、治疗和康复方案。

## 暂不适合谁

- 出现急性、进行性或可能危及生命健康情况的人；
- 正在处理重大疾病、复杂慢性病、术后恢复或其他需要医疗专业人员持续管理的人；
- 希望判断症状原因、疾病风险或病情轻重的人；
- 只想获得具体药物、补剂或治疗处方的人；
- 希望获得“根治保证”的人；
- 不愿提供完成审计所需的基本事实，或要求无限期咨询的人。

“亚健康”不是由本服务作出的判断。只要是否存在疾病或医疗风险无法确认，创始版就不接收。

## 创始版输入

以“一个非诊疗目标”为限：

- 问题出现和变化的时间线；
- 做过的检查和获得的专业意见；
- 使用过的产品、设备、课程、机构和大致花费；
- 每项尝试的目标、频率、持续时间和主观效果；
- 用户最希望梳理的三个非医疗行动或专业确认问题。

只收集完成审计必要的资料。用户应优先提交脱敏副本，不收集身份证号码等无关信息。

## 创始版交付

- 6—10 页健康投入复盘报告；
- 1 页路径地图；
- 过去投入与目标分类；
- 目的相近的项目、信息缺口和“目前无法验证”的原因；
- 供下一位医生或其他合格专业人员确认的问题清单；
- 未来 30 天最重要的 3 个非医疗行动；
- 一次 45 分钟线上交付沟通。

## 不交付

- 疾病诊断；
- 对症状原因和病情轻重的判断；
- 重大疾病、慢性病、术后或康复治疗的管理；
- 个体化处方或治疗方案；
- 停药、换药或调整剂量建议；
- 对某项治疗的保证；
- 无限期答疑与陪伴。

## 创始版实验

- 名额：5 人；
- 价格假设：999 元/人；
- 目标：验证用户是否愿意为“把健康消费和下一步确认事项盘清楚”付费；
- 每例交付后必须访谈并记录实际工时、最有价值部分、未解决问题和转介绍意愿。

## 成功标准

首轮结束时至少满足三项，才考虑继续标准化：

- 5 个名额中至少 3 个为真实付费；
- 至少 3 位用户能明确说出一个因此改变的非医疗行动，或一个准备得更清楚的专业确认问题；
- 至少 2 位愿意主动推荐类似用户；
- 交付范围能控制在可接受的工时内；
- 没有依赖越界医学判断才能产生价值。
