# 就医准备与医疗资源信息导航

> 状态：待专项合规审查的可选模块，当前不公开销售。

## 一、产品定位

在用户已经由合格医疗专业人员明确就诊方向后，帮助用户查找和比较官方公开的医疗资源信息，并准备下一次就诊。

它是信息检索和就医准备服务，不是医疗转诊、分诊、诊断或专家推荐。

## 二、进入条件

用户必须同时满足：

1. 符合健康投入复盘的非诊疗边界，不涉及重大疾病、急性或进行性情况；
2. 已有合格医疗专业人员明确的诊断、科室方向或转诊意见；
3. 不要求健年根据症状或病历判断应该看什么科、找什么医生；
4. 能说明可接受的地理范围、时间、预算和其他非医疗偏好；
5. 接受最终选择由用户本人和接诊医疗专业人员决定。

如果用户只有尚未评估的症状，应使用医疗机构官方分诊、首诊或医生转诊流程，本模块不代替分诊。

## 三、可以交付

### 1. 医疗资源候选信息卡

提供 3—5 个候选，不作第一名排序。每张卡只使用可核验的客观信息：

- 医院、科室和医生的官方名称；
- 医院官网对专业方向和门诊范围的描述；
- 卫生健康主管部门或医院公开的重点专科、医学中心等客观信息；
- 医生官方简介、执业地点、公开职称和专业方向；
- 城市、交通、出诊地点、官方预约渠道和公开费用信息；
- 信息核验日期和当前无法确认的事项。

### 2. 不排序的比较表

根据用户已经明确的非医疗约束比较：

- 城市和出行成本；
- 预约等待和公开门诊时间；
- 是否有官方描述的相关专业方向；
- 是否支持用户需要的语言、线上复诊或其他公开服务；
- 用户已有转诊意见中提到的客观条件。

不设置“权威分”“疗效分”和“最适合度”。科研论文数量、网络口碑和平台评分不能直接代表临床能力。

### 3. 就诊资料包

- 现有病历、检查、影像和用药清单的整理目录；
- 一页问题时间线；
- 用户最希望医生回答的 3—5 个问题；
- 医院官方明确要求携带的资料和流程信息。

### 4. 问诊沟通提纲

帮助用户按“主要困扰—持续时间—已经做过什么—结果如何—最想确认什么”的顺序表达，提高沟通效率，但不替用户回答医学问题。

## 四、不能交付

- 宣称某位医生或医院“最权威”“最好”或“最适合你”；
- 根据未评估症状替用户选择科室、医生或就医层级；
- 对医生、医院、治疗效果和医疗安全作主观排名或保证；
- 告诉用户“必须提前做”哪些检查、检验或影像；
- 解读检查结果并据此匹配医生；
- 代替医生作转诊决定；
- 提供加号、黄牛号源或非官方预约渠道；
- 从医院、医生、平台、药品、器械或检查项目获取推荐佣金；
- 将用户案例与具体医疗机构、医生绑定后公开宣传。

## 五、检查准备的替代表达

不能写：

> 你必须先做核磁、CT 和某项化验再去看医生。

可以写：

> 请携带已有检查和影像原片。是否需要补充检查，应由接诊医师结合你的情况决定。我们为你整理了三个可以在就诊时确认的问题。

如果医院官方预约页面明确要求携带某项既有资料，可以原样转述并标注来源和核验日期；不得把医院流程说明扩展为健年的医学建议。

## 六、信息来源规则

优先使用：

1. 医院和科室官方网站、官方公众号或官方预约平台；
2. 国家和地方卫生健康主管部门公开信息；
3. 医师执业注册和医院资质的官方查询渠道；
4. 政府公布的医学中心、临床重点专科等名单。

商业排行榜、搜索广告、平台付费排序、自媒体榜单和患者评价只可作为待核验线索，不进入最终候选理由。

所有信息在交付前重新核验，记录来源链接和核验日期。出诊信息变化频繁，必须提醒用户以医院最终安排为准。

## 七、利益冲突与收费

- 用户支付的是信息检索和整理费用，不是介绍费或转诊佣金；
- 不接受医疗机构、医生或挂号平台的候选位付费、成交分成或隐性返佣；
- 如果未来存在任何合作关系，相关对象不得进入默认中立候选清单，且必须单独披露并完成法律审查；
- 不承诺挂号成功、医疗效果或就医结果。

零佣金能够减少利益冲突，但不能单独证明这种服务不构成医疗广告、转诊或其他受监管活动，仍然需要结合实际页面、合同、收费和交付流程进行法律审查。

## 八、上线前置条件

- [ ] 中国大陆医疗与广告合规律师完成专项审查
- [ ] 明确营业范围、合同名称、发票项目和退款规则
- [ ] 确认信息呈现不构成医疗广告或变相医疗服务推介
- [ ] 建立统一、可复核、无付费排序的候选标准
- [ ] 建立信息过期、医生停诊和用户投诉处理流程
- [ ] 完成利益冲突披露和零佣金制度

## 九、如果未来要提供更强的“匹配”能力

以下能力不能由健年当前团队自行提供，应由依法开展相关服务的医疗机构和有资质医师承担医学判断与责任：

- 根据症状和病历选择就诊科室；
- 判断是否需要转诊或跨地区就医；
- 判断哪位医生在医学上更适合；
- 建议就诊前需要完成的检查；
- 提供医学第二意见和治疗方案比较。

健年可以在这样的合作中承担用户授权后的资料整理、隐私处理、公开信息检索、预约流程和出行协助，但不能把合作医生的医学责任包装成健年自己的非医疗服务。
