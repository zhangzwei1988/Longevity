# 健康路径审计用户信息表

> 本表只用于服务设计。正式收集时应使用具备适当权限和隐私说明的工具，不要让用户把可识别病历直接提交到 Git 或普通群聊。

## 一、你最想解决的一个问题

1. 这个问题给你的生活带来了什么具体影响？
2. 它大约从什么时候开始？过去一年如何变化？
3. 如果本次审计只能帮你做出一个决定，你希望是什么？

## 三、现有资料

- 有哪些检查报告、影像报告或专业意见？
- 哪些资料仍然有效，哪些已经过期？
- 是否存在互相矛盾的意见？
- 是否已经对姓名、电话、身份证号、病历号、二维码、地址和签名等信息完成脱敏？

## 四、效果如何被判断

- 你现在用什么指标判断自己变好或变差？
- 是否有开始前的基线？
- 是否在固定时间复测？
- 有没有出现“感觉有效，但无法确认”的尝试？

## 五、现实约束

- 每周能投入多少时间？
- 对下一阶段预算有什么限制？
- 哪些事情无论如何不愿意做？
- 是否已有固定医生、治疗师、教练或其他专业人员？
