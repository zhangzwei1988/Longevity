# 问题领域循证知识简报标准

> 目的：把可靠的健康信息变得可理解、可核查、可用于准备专业沟通，而不是为用户作个体诊断和治疗建议。

## 一、简报回答什么

围绕用户关注的问题领域，回答：

1. 这个领域目前有哪些相对稳定的通用认识？
2. 权威指南通常如何描述评估和管理框架？
3. 哪些说法证据较强，哪些仍不确定或存在争议？
4. 对普通成年人有哪些公开、一般性的生活注意事项？
5. 用户下一次与合格专业人员沟通时可以问哪些问题？

简报不回答：

- 用户到底患有什么疾病；
- 某项研究是否证明某种方法适合该用户；
- 用户应选择哪种治疗、康复、药物、补剂或剂量；
- 某位医生的判断是否正确；
- 用户是否可以不就医、停止复诊或改变治疗。

## 二、来源优先级

按以下顺序寻找和使用证据：

1. 中国国家卫生健康主管部门、WHO 等权威公共卫生机构的现行文件；
2. 相关专业学会的现行临床实践指南和共识；
3. 系统综述和 Meta 分析；
4. 高质量随机对照试验；
5. 与问题直接相关的高质量观察性研究。

新闻、商业机构文章、杂志报道和社交媒体只能用于发现线索，不能作为关键结论的最终依据。预印本、单个动物实验和无法核实来源的二手文章不进入用户结论。

## 三、每份简报的固定结构

### 1. 先说结论

最多 5 条，每条使用普通语言，并标记证据强度：较强、中等、有限或存在争议。

### 2. 适用范围

说明证据研究了哪些人、不适用于哪些人，以及为什么不能直接套到用户个人情况。

### 3. 一般生活注意事项

只纳入权威公共卫生建议或适用于一般成年人的低风险内容。不得根据用户病历生成个体饮食、运动强度、康复动作、补剂或治疗方案。

### 4. 常见误解

解释营销话术、相关性与因果性、短期指标与长期结果等常见误区，不评价用户现有医生和治疗。

### 5. 专业沟通问题

将知识转化为 3—5 个用户可以向合格专业人员提出的问题，不替专业人员回答。

### 6. 来源与限制

每条关键结论标注来源名称、发布机构、年份、链接、适用人群和主要限制。资料超过预设更新时间或指南已更新时必须重新检索。

## 四、专业审核要求

- 研究整理可以由团队完成，但医疗专业结论不得由无资质人员自行定稿；
- 在未确认账号、团队和交付方式符合相关资质与平台要求前，默认不自行生产原创专业医疗科普；
- 涉及疾病预防、治疗、康复或专业医疗科普的内容，应由对应领域的合格专业人员承担编写或审核责任，并在上线前复核这种合作方式是否满足监管与平台要求；
- 对外披露内容整理者和审核者的真实专业背景，不暗示不存在的医师资质；
- 使用 AI 辅助检索或起草时，由人核对原文、结论、适用范围和引用；
- 如果无法满足资质、编写和审核要求，就缩小为权威公开资料目录、忠实通俗摘要和专业沟通问题，不输出原创专业结论。

## 五、质量检查

- [ ] 每个关键结论能回到原始来源
- [ ] 没有用单篇研究替代指南或共识
- [ ] 没有把群体结果直接套到用户个人
- [ ] 明确写出适用范围和不确定性
- [ ] 一般生活建议没有越过低风险公共健康范围
- [ ] 医疗专业内容已由适当专业人员审核
- [ ] 没有夹带产品、机构、药物或器械推销
- [ ] 用户能够在 5 分钟内读懂核心结论
