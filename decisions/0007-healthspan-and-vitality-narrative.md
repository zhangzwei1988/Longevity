# 决策 0007：以“活力人生”解释健康寿命

- 日期：2026-07-19
- 状态：已决定，待用户验证

## 决定

健年的品牌目的表达为：

> 让有活力的人生，尽可能长。

“科学养生，少走弯路”保留为品牌方法口号。当前首款产品仍从健康投入混乱和不知道下一步的现实问题切入。

## 叙事层级

1. 品牌目的：延长保持活力、独立和自主的生命阶段；
2. 长期逻辑：未来的生活能力需要从更年轻时开始积累；
3. 品牌方法：持续识别最值得优先关注的一环，行动、记录并复盘；
4. 当前产品：先识别信息、认知、执行和资源上的管理断点。

## 边界

- 不承诺降低生理年龄、提高预期寿命或延长具体年数；
- 不把衰老时钟作为当前产品结果或效果证明；
- 不宣称能够自行“精准诊断身体短板”；
- 身体机能、疾病和医学风险由对应领域的合格专业人员评估；
- 对外可以使用“关键短板”这一通俗比喻，但必须说明健年当前识别的是管理优先级和专业确认事项。

## 原因

用户未必追求单纯活得更久，但普遍不希望过早失去行动能力、精力和生活自由。“活力人生”比寿命数字更符合用户心智，也能把健年的长期定位与当前产品连接起来。
