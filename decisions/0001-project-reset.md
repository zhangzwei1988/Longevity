# 决策 0001：以健年为母品牌重建项目

- 日期：2026-07-18
- 状态：项目重建决定继续有效；首个产品定位已由 `0005-reposition-to-ten-year-health-inventory.md` 更新

## 决定

在 `/Users/john/CodeShop/Studio/Longevity` 建立独立项目，以 Markdown 文档管理战略和运营；原项目保持只读。

采用以下结构：

- 健年 Healthspan：母品牌；
- 多活十年 Lab：当前主账号；
- 健年·未来十年健康盘点：首个付费产品；
- 健年本地病历脱敏工具：未来免费信任工具；
- 垂直账号：由真实订单触发，不在启动阶段同时建设。

## 原因

原项目积累了大量品牌、内容和流程资产，但商业入口不够清晰，且存在系统先于需求、内容生产过重、体检报告解读吸引力不足等问题。

新项目优先验证：用户是否愿意为健康投入和解决路径的整理、排序与下一步决策付费。

## 后果

- 未来 90 天重点是访谈、成交和人工交付；
- 暂不开发网站、App、自动医学判断或多账号矩阵；
- 所有文档都必须服从真实用户证据；
- 原项目只作为历史参考，不再作为当前事实源。
