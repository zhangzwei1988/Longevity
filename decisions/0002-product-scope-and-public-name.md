# 决策 0002：收窄服务边界并更换前台商品名

- 日期：2026-07-18
- 状态：服务边界继续有效；商品名已由 `0005-reposition-to-ten-year-health-inventory.md` 更新

## 决定

1. 创始版不处理重大疾病、急性或进行性症状、已确诊疾病治疗、术后和专业康复、药物及其他医疗决策。
2. 不使用“我们只做亚健康”作为主要边界，因为健年没有资格判断用户只是亚健康，也不能排除潜在疾病。
3. 采用任务型准入：只做健康消费复盘、非处方生活方式执行复盘和就医资料整理。
4. 边界不清时不接单；交付中发现越界时立即中止。
5. 用户侧商品名改为“健年健康投入复盘”；“健康路径审计”保留为内部方法名。

## 对外表达结构

- 传播钩子：健康上花了这么多钱，为什么还是不知道下一步？
- 商品名：健年健康投入复盘
- 一句话解释：把过去一年买过的、做过的、被建议过的健康方案盘一遍，看清信息缺口，以及下一步应该向谁确认什么。
- 内部方法：健康路径审计

## 原因

“健康路径审计”对普通用户陌生，不能在第一眼说明购买理由；“健康投入复盘”直接连接用户已经发生的花费、尝试和困惑。

同时，“亚健康”不是一个足够安全的运营边界。项目不具备诊断或排除疾病的资质与能力，因此必须依靠严格的任务范围、排除条件和中止流程保护用户。
